Developer Tools / Plugins / Addons

2D Dungeon Generator for Godot .NET

I have been developing a 2D Dungeon generator to release on the Godot asset store for free or low cost. And to use in my own projects.

  • Any complete tileset as per the Godot documentation can be plugged in for the floors / walls
  • decorations can be created using Godot's build in pattern tool for tilesets.

Desktop Software (non Game related)

Desktop Invoice Management App in C++

An open source, free invoicing solution. A friend and I wanted just a lightweight desktop application to use for a small business. Aimed at tech-savy users, who are able to backup, store and secure their own data.

  • No built-in online storage, saved locally by default.
  • Lightweight Invoicing app, backup and secure your own data.
  • Sync the app's data folder and it can be used on multiple devices.
