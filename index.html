Developer Tools / Plugins / Addons

2D Dungeon Generator for Godot .NET

I have been developing a 2D Dungeon generator to release on the Godot asset store for free or low cost. And to use in my own projects.

  • Any complete tileset as per the Godot documentation can be plugged in for the floors / walls
  • Decorations can be created using Godot's build in pattern tool for tilesets.
  • Supports animated tiles. E.g. see candles at 0:18.

Desktop Software (non Game related)

Desktop Invoice Management App in C++

An open source, free invoicing solution. A friend and I wanted just a lightweight desktop application to use for a small business. Aimed at tech-savy users, who are able to backup, store and secure their own data.

  • No built-in online storage, saved locally by default.
  • Lightweight Invoicing app, backup and secure your own data.
  • Sync the app's data folder and it can be used on multiple devices.

    React Native Mobile and Web app

    For my final year Capstone project we created a React Native application for the Junior Rangers program with DETSI. I was the lead developer and was solely responsible for the backend server and database, as well as the primary developer on the frontend.

    • Server was built with Node.js using Express
    • Client was build with React Native and Expo Go
    • SMS authentication implemented with Twilio
    • Used websockets for immediate updates for announcements, reactions, club membership and account updates.
    • IOS, Android and Web builds.
    • Read-aloud features for low-literacy audiences.
    • Can switch between multiple logged in users easily.
    • Club management features for Rangers with more than one club.
    • Test out the web build: https://junior-rangers-client.vercel.app/ - You'll need to signup as a Ranger first.
      (Disclaimer: This prototype is only to showcase with portfolios, is not an official approved app by DETSI for public use.)
